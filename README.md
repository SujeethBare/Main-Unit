Architected a leader follower platooning system for fleet logistics and military convoys, enabling unmanned trailing vehicles to autonomously track a single lead vehicle
Integrated RPLidar-based 360° mapping and trajectory tracking on a Raspberry Pi 4 lead unit, with Arduino motor control over SPI
Built Arduino follower units using ultrasonic/IR sensing and encoder-based motor control to maintain convoy spacing; research accepted at IEEE PESGRE ‘23
